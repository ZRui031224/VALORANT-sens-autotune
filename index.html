FPHYSICS

桌面前置检查

Windows 指针加速、浏览器缩放、鼠标锁定都会影响测量。先确认这三项再测。

· Windows「提高指针精确度」建议关闭 · 浏览器缩放保持 100% · 鼠标锁定：点击测试后自动请求

测量前的桌面检查

  1. 关闭 Windows 指针加速：设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标设置 → 指针选项 → 取消“提高指针精确度”。
  2. 浏览器缩放 100%：Ctrl + 0。缩放会改变画面像素与鼠标位移的对应关系。
  3. 用原始输入：本页会请求 unadjustedMovement（绕过系统加速）；若浏览器不支持会退回普通锁定，精度会略降。
  1. 确认 DPI：在鼠标驱动里读取，或按住 DPI 键切到固定档位，不要用“DPI 切换键”边玩边换。
  2. 16:9 画面：测试区强制 16:9 并锁定 103° 横向 FOV，与游戏默认一致；带鱼屏 / 4:3 拉伸会让手感略有差异。
  3. 一次测完：中途不要改 DPI、不要改分辨率，否则前后轮次不可比。

游戏内路径：设置 → 常规 → 鼠标 → 灵敏度：瞄准。输入框支持三位小数，直接键入即可。

这个数值是怎么来的

    每一步都可以追溯。如果你不同意某条调整，可以在“三档取值”里直接选相邻档位。

    三档取值

    稳定型 · 精准优先 0.330 更慢，微调更稳，适合架点与狙击
    平衡型 · 首选 0.350 测试得出的最优点，速度与稳定兼顾
    速度型 · 转点优先 0.372 更快，转身与切枪更灵活，需要适应

    填入游戏

    1. 打开《无畏契约》→ 设置 → 常规 → 鼠标，找到“灵敏度：瞄准”。
    2. 把数值改成 0.350。可以直接用键盘输入，游戏接受三位小数。
    3. 鼠标 DPI 必须保持 800 不变；若你在驱动里改了 DPI，请用本页重新换算一次。
    4. 开镜 / 狙击倍率先保持 1.000；如果你原来调过，用下方换算器把旧倍率一起迁移过来。
    5. 进训练场打 3 轮困难机器人，只做 ±0.005 级别的微调；不要一局一改，至少适应 2–3 天再评价。
    新倍率 1.000

    原理：开镜倍率是叠加在“灵敏度：瞄准”之上的。换了主灵敏度后，按 新倍率 = 旧灵敏度 × 旧倍率 ÷ 新灵敏度 重算，开镜手感才不会跟着变。

    换 DPI 换算 → 灵敏度 0.184

    保持同一个 cm/360°，只改鼠标 DPI 时用这一行换算。
